## 便宜年付机的五个检查项

这部分是本文真正想给的东西。$11/年、¥349/年 这种价格，坑不在贵不贵，在买完之后才发现条件不对。用今年已经能查到数据的几家做例子。

### 1. 首期价和续费价是不是一回事

Hostinger 黑五页到 12.14，KVM1（1C4G/50G/4T）折合 **$6.49/月**、KVM2（2C8G/100G/8T）**$8.79/月**，但必须一次预付 **24 个月**，续费回到 **$11.99 / $14.99**。首期和续费差了一倍左右，两年一付把低成本锁住了，第三年开始按原价走。

反过来，RakSmart 官方博客把「充值满 $100 得全场 6.5 折券、续费折扣同享」写成卖点，这种就要在结账页确认券的有效期和适用范围，因为「同享」通常附带「在券有效期内」这个前提。

**检查动作**：结账前把首期总价除以月数，再单独看一眼续费价那一栏。年付机被低首年价吸引，第二年按原价续，是很常见的失手方式。

### 2. IP 是不是当地原生

NoslaCloud 这一季的四个机房，洛杉矶是**美国原生 IPv4**，法兰克福是**德国原生 IPv4**，但圣何塞和东京的 IPv4 都是**德国广播 IP**，只是部署在美国和日本。对建站、需要本地 IP 属性的业务，这条差别很实在。

**检查动作**：产品页写「原生 IP」和写「广播 IP」是两回事，写「XX 广播 IP 部署于 YY」的，按广播 IP 处理。

### 3. 流量是单向还是双向计费

NoslaCloud 全系**双向计费**，500GB/月 意思是进出加起来 500GB。HostDZire 孟买那档 €18/年（1C2G/500G SATA）、€21/年（EPYC 2C4G/40G NVMe）同样标了双向计流。双向计费和单向计费在同样的数字下，实际可用量能差一半。

**检查动作**：看流量那一栏有没有写「双向」。没写的，去条款或工单问清楚。

### 4. 限量、限购、售罄

NoslaCloud 每款套餐**每个账户限购 1 台**。PureVoltage 每户**限新购 2 台**。Nuyek 独服**限 20 台**、小鸡首发 15 台之后每天放 1 台到 2027 年 1 月 1 日。华纳云香港/东京轻量 ¥246/半年 那款，盘点时是一款售罄、一款补货中。

限量款的价格通常是真的低，但需要抢，而且抢不到就是没有。

**检查动作**：看到明显低于同类的价格，先找限量说明，再决定要不要把它当主方案。

### 5. 优惠能不能叠加

RakSmart 这一季有个口径冲突：官方博客写「部分优惠支持叠加使用」，而第三方盘点在直链表格里写「秒杀款不叠券，续费看结算页」。两种说法都有出处，无法合成一个确定结论。

**检查动作**：这类冲突不要按「大概率能叠」去算预算，一律以结账页实际扣减为准。
